# Веб-сервис магазина косметики (REST API)

Бэкенд-сервис для управления карточками услуг (товаров) и пользователями. 
Разработан на языке Go с использованием фреймворка Gin, ORM GORM и объектного хранилища MinIO (AIStor) для медиафайлов.

Проект представляет собой REST API, который в дальнейшем будет использоваться для SPA (Single Page Application) фронтенда.

## 🛠 Технологический стек
* **Язык:** Go 1.22
* **Веб-фреймворк:** Gin
* **ORM:** GORM
* **База данных:** PostgreSQL 16
* **Хранилище файлов:** MinIO (Silo/AIStor)
* **Контейнеризация:** Docker Compose

## 🚀 Запуск проекта

1. Убедитесь, что у вас запущен Docker Desktop.
2. Поднимите контейнеры с базой данных, админкой и MinIO:
   ```
   docker compose up -d
   ```
3. Запустите бэкенд-сервер:
   ```
   go run ./cmd/product_categories
   ```
## HTTP Методы (API)

Все запросы начинаются с префикса `/api`. 
*Текущий пользователь (создатель) зафиксирован на бэкенде через константу (`ID = 1`).*

### Домен: Услуги (Services)

| Метод | URL | Описание | Формат данных |
| :--- | :--- | :--- | :--- |
| **GET** | `/api/services` | Список опубликованных услуг. Есть фильтр по цене (`?min=100&max=5000`). Возвращает флаг `is_owner` (моя ли карточка). | — |
| **GET** | `/api/services/feed` | Лента (1 карточка). Без ID отдает первую. С параметром `?next=true` отдает следующую. Возвращает флаг `is_liked` (лайкнул ли я). | — |
| **GET** | `/api/services/draft` | Получить свой черновик (не более 1 шт). Если нет — вернет `404`. | — |
| **POST** | `/api/services` | Создать карточку в статусе `draft`. Загружает файлы в MinIO, в БД пишет ключи. | **form-data**: `title`, `description`, `price`, `category`, `image`, `video` |
| **PUT** | `/api/services/{id}/publish` | Опубликовать карточку (смена статуса на `published`). Работает только для своих. | — |
| **DELETE** | `/api/services/{id}` | Логическое удаление (смена статуса на `deleted`). Работает только для своих. | — |
| **POST** | `/api/services/{id}/like` | Поставить или убрать лайк. | **JSON**: `{"like": 1}` (1 — вкл, 0 — выкл) |

###  Домен: Пользователи (Users)

| Метод | URL | Описание | Формат данных |
| :--- | :--- | :--- | :--- |
| **POST** | `/api/users/register` | Регистрация нового пользователя. | **JSON**: `{"username": "user", "email": "mail@mail.ru"}` |

##  Таблицы базы данных

### 1. `users` (Пользователи)
* `id` — первичный ключ
* `username` — имя (уникальное)
* `email` — почта (уникальная)

### 2. `services` (Услуги)
* `id` — первичный ключ
* `title` — название карточки
* `description` — описание
* `status` — статус (`draft`, `published`, `deleted`)
* `image_url` — ключ картинки в MinIO
* `video_url` — ключ видео в MinIO
* `price` — цена (поле по теме)
* `category` — категория (поле по теме)
* `creator_id` — внешний ключ на автора (`users.id`)
* `created_at` — дата создания
* `published_at` — дата публикации

### 3. `likes` (Лайки)
* `id` — первичный ключ
* `user_id` — внешний ключ на `users.id`
* `service_id` — внешний ключ на `services.id`
